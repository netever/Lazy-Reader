# Замеры скорости

Цель — быстро показать текст последней книги. Порог времени запуска владелец выбирает в конце фазы 0 по замерам на своих устройствах (SPEC, раздел 8).

## Что и как меряем

**Холодный старт** — от запуска до первой страницы последней открытой книги. Приложение не работало в памяти. Перед замером откройте в приложении книгу и оставьте её открытой: при запуске приложение сразу открывает последнюю книгу.

Приложение пишет метки в лог и в файл `perf.log` в каталоге данных (README, «Где приложение хранит данные»):

```text
PERF first_page since_main_ms=… since_process_ms=… epoch_ms=… format=epub
```

- `since_process_ms` — от создания процесса (только Android и Linux).
- `since_main_ms` — от запуска кода Rust; не учитывает загрузку самого процесса.
- `epoch_ms` — время по часам, по нему скрипты для Windows и macOS считают время от запуска.

Другие метки: `js_start` (интерфейс начал работу), `app_ready`, `pdf_open` (документ PDF разобран), `page_turn` (плавность перелистывания: кадров в секунду и самый долгий кадр).

### Android (делает владелец на самом слабом телефоне)

1. Включите на телефоне режим разработчика и отладку по USB, подключите к Mac.
2. Установите отладочную сборку (README, раздел Android) или релизную, когда она появится. **Для итоговой цифры нужна релизная сборка**: отладочная заметно медленнее.
3. Откройте в приложении книгу, например `test-books/sample.epub`.
4. Выполните:

```bash
source scripts/env.sh && scripts/measure-start-android.sh 10
```

5. Перешлите Claude Code вывод скрипта: модель телефона, 10 замеров и медиану.

### Windows (делает владелец)

1. Установите приложение из артефакта GitHub Actions (README, раздел Windows), откройте книгу и закройте приложение.
2. В PowerShell из папки репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\measure-start-windows.ps1 -Exe "$env:LOCALAPPDATA\Lazy Reader\lazy-reader.exe" -Runs 10
```

Путь к `.exe` зависит от установщика: если файла нет, найдите его через ярлык в меню «Пуск» (Свойства → Объект).

3. Перешлите вывод скрипта.

### Плавность перелистывания

Включите «Анимация» в читалке и перелистните 10–20 страниц касанием края экрана. Внизу экрана видна последняя цифра. Все замеры лежат в `perf.log` строками `page_turn`. Ориентир: 55–60 кадров/с и худший кадр не больше 50 мс. Рывок — кадр дольше 50 мс.
