# ADR 0003. Проверка лицензий и MPL-2.0

Статус: принято.

## Контекст

Владелец разрешил разрешительные лицензии (SPEC, раздел 2). MPL-2.0 допустима для неизменённых зависимостей одной записью в ADR. В дереве зависимостей Tauri есть крейты под MPL-2.0 (`cssparser`, `selectors`, `dtoa-short`, `option-ext`), а также Zlib, Unicode-3.0 и другие разрешительные лицензии.

## Решение

- MPL-2.0 разрешена для транзитивных зависимостей, если мы не меняем их файлы. Это решение покрывает все такие крейты, отдельные ADR не нужны.
- Rust: `cargo deny check licenses` с конфигурацией `src-tauri/deny.toml`.
- npm: `npm run licenses` (проверка только зависимостей, которые попадают в сборку, без dev-зависимостей).
- Тексты лицензий для экрана «О программе → Лицензии» собираются автоматически в фазе 1.

## Последствия

- Новая зависимость с лицензией вне списка ломает проверку. Тогда Claude Code останавливается и спрашивает владельца.
